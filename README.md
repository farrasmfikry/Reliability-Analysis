# Reliability Analysis
A Python toolkit for wind turbine reliability and FMEA analysis.

Background
Reliability analysis is an approach to minimizing failure of components in wind turbine. This will reduce the Levelized Cost of Energy (LCoE), an economic metric to predict the average net present cost of generating electricity, because reliability directly affects operation and maintenance costs. Understanding reliability parameters like mechanical degradation, environmental stress, operational load and fatigue is crucial to reducing unplanned downtime in wind turbine development.

This exercise will calculate and plot several outputs.
1. Weibull Analysis
2. FMEA/FMECA (Failure Mode, Effects, and Criticality Analysis (FMECA)
3. Root Cause Analysis

We use open-source Kelmarsh wind farm data from https://zenodo.org/records/5841834#.YgpBQ_so-V7
